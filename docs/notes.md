# Part 4: Conda and Google Colab

## Comparison of pip, venv, and Conda

| Tool | What it does |
|---|---|
| pip | Installs and manages Python packages. |
| venv | Creates an isolated Python environment for a project. |
| Conda | Manages Python versions, packages, and environments. |

## Google Colab vs Local Jupyter

I would choose Google Colab when I need an online notebook and access to a cloud GPU without configuring my computer.

I would choose local Jupyter when I want to work with local files, have more control over my environment, or work offline.

## Conda Demo Answer

The command `python --version` should print Python 3.11.x inside the demo environment because it was created with Python 3.11.
